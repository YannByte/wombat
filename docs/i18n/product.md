# 产品语言与文案

中文 | [English](product.en.md)

本页定义 CLI 的展示语言，以及面向用户的页面与文案规则。文档配对由[双语文档流程](workflow.md)管理。

## 使用

```sh
wombat --lang en
wombat usage --lang zh
wombat system doctor --lang en
WOMBAT_LANG=en wombat --help
```

语言优先级为 `--lang`、`WOMBAT_LANG`、系统语言、中文兼容默认值。支持 `zh` / `en` 及其地区标签。系统语言依次取非空的 `LC_ALL`、`LC_MESSAGES`、`LANG`，均未设置时使用运行环境的语言；`C` / `POSIX` 使用英文。显式指定不支持的语言报参数错误，无法匹配的系统语言回退中文。


## 用户页面与文案规则

以下规则用于编写和审阅页面、弹窗、表单、提示、CLI 帮助及错误信息；它们是维护要求，不表示所有现有页面均已完成验收。中英文技术说明按[语言审校规则](workflow.md)应用 ASD-STE100；按钮、菜单和短标签遵循各自语言及界面的惯用表达，不为凑成完整句子而增加冗余文字。

- 从用户任务组织信息：先说明用户正在查看什么、结果意味着什么、接下来可以做什么，再按需提供方法和技术依据。默认使用用户熟悉的产品术语；仅在定位问题、核对证据或作出决定时展示实现细节，不直接用内部模块名、协议术语或开发状态解释产品操作。
- 页面标题说明对象或任务，按钮说明动作和必要的目标，链接说明去向。同一动作使用一致名称，优先使用「查看详情」「重试」「清除筛选」等具体表达，避免孤立的「处理」「确定」或「点击这里」。按实际行为区分查看、保存、重新检查及交给 Codex 处理，不把建议写成已执行结果。
- 中文使用自然、简洁的动宾结构和中文标点，避免英文词序、生硬被动句及名词堆叠。英文操作使用明确动词，标签使用一致的句首大写方式，保留专名拼写。根据上下文处理冠词、单复数和语气，避免逐字对应。日期、数字和单位沿用展示语言的格式约定；来源原文和稳定标识保持原样。
- 状态须说明当前事实和影响，区分加载中、无数据、筛选无匹配、缺少权限、读取失败、部分结果和旧结果。已有证据足以确定时应呈现可确定的值或状态；未开始、进行中、失败、来源未记录、不支持及不适用须分别处理，不适用的信息不展示。零值、缺失值与未计价不可互换；确实缺少证据时不得编造零值或原因。估算金额和观测范围须明确。错误信息先说明哪个操作失败及受影响对象，再提供实际可用的恢复动作；没有证据时不推断原因，不承诺成功或恢复时间。
- 遵循常见交互习惯：按钮执行动作，链接用于导航，输入框具有明确标签，占位文字只补充示例。保存、取消、返回和重试须对应实际行为；有必要时说明禁用原因。对具有破坏性或难以撤销的操作，在执行前说明对象、后果和能否撤销；确认文案须明确动作，不得代替实际授权检查。
- 用户须能在键盘操作、窄屏及辅助技术下理解必要信息。可访问名称应包含可见标签中的动作或对象；不得仅靠颜色、图标、悬停或占位文字表达状态、错误或必要说明。文案在换行、数量变化和语言切换后仍须完整，不将英文语法拼接方式照搬到中文。
- 计时、Token 与规则检查都应尽量提供有用的解释，不以精确数值作为展示的前提。有明确依据时可显示估算或范围，并说明方法和适用范围。区分精度受限与无法得出结论；只有缺失信息确实影响判断时，才提示依据不足，并说明影响。规则检查须说明检查内容与结论范围，不以泛化的未知状态代替解释。
- 审阅时分别通读中英文，并结合实际界面检查信息顺序、操作名称、恢复路径、长标题、零值、缺失值及单复数。用合成内容检查长文本、窄屏、键盘操作和语言切换；报告实际覆盖的状态。字典和配对检查通过不能代替用户视角、可访问性或语言质量审阅。

## 模块边界

- `@wombat/client/locale` 是独立的纯 TypeScript 公开入口，不依赖 Node、React 或 Rust。它提供 `LocaleRuntime`、`resolveLocale`、类型化 `t`、语言读取与切换；每个 CLI 进程使用独立展示实例。
- `client/src/locale/zh.ts` 与 `en.ts` 保存完整消息，以功能前缀划分键；英文键集合由中文键集合约束。参数名从中文模板推导，双语参数一致性另由检查脚本验证。正文参数按原值插入，不递归解析或翻译。
- CLI 负责解析语言参数和环境变量。模块级标签使用延迟读取，避免启动时捕获旧语言。界面操作使用稳定标识，不能根据翻译后的文字判断业务动作。
- 语言影响帮助、提示、标签、日期和紧凑数字展示。JSON 字段、错误码、模型标识、来源标题、用户内容及用量/金额不翻译。已知内核与宿主进度在展示层映射；未知内核诊断与来源问题原样保留。
- 数量消息使用完整模板及原生 `Intl.PluralRules` 选择单复数；零、未知及两个独立计数分别处理。月桶展示本地语言的年月，不将日历日期转为宿主时区。配置指令 Token 标为估算，列表大小使用 KiB（1,024 B），保留准确字节证据并按原始数值排序。

## 验证与限制

`corepack pnpm i18n:check` 检查中英文静态字典的缺失、重复及空条目、插值参数一致性和混用语言，也会检查 CLI 中选定展示位置的硬编码文案。源码检查会校验有限的翻译键和 `@wombat/client/locale` 绑定，并跟踪同一文件内的常量、无参 helper 返回值及受限条件拼接；它还能识别直接把翻译结果存入 React state 的情况。检查使用 TypeScript 语法树并跳过注释，不是通用跨文件数据流分析。动态跨文件拼接可能漏检；检查通过不能证明译文质量或完整运行时覆盖，仍须按上述规则人工审阅实际界面和语言切换。

`corepack pnpm test:repo` 验证检查器的故障样本；模块测试覆盖语言优先级、运行时切换、展示格式化；构建后的端到端测试确认语言不改变共享内核数据。范围为中英 CLI 展示，未增加任意语言插件、通用语法表达式语言、从右到左布局、文档网站或内核诊断全文翻译。
