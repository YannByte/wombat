# 本机 Web 宿主

中文 | [English](web-host.en.md)

`@wombat/web` 导出 `startWebHost(options)`，返回浏览器 URL、origin 、异步 `close()` 与受限 `openView(request)`。CLI 注入 Node 客户端；宿主不拥有计价、查询或来源解析规则。

## 访问与资源限制

宿主仅监听 127.0.0.1，默认自动分配端口。宿主复制启动范围，后续授权变更保存在宿主自己的状态中；不修改传入的选项，也不将临时授权提升为启动范围。来源范围由启动参数与宿主管理的目录授权确定；HTTP 调用者不能传入任意根或快照路径。宿主最多保留 128 个已返回快照身份，内核版本保留期独立；版本过期明确失败，需重新查询当前版本。

启动生成随机令牌，放在 URL fragment 中，由浏览器移入 sessionStorage 并清除地址栏 fragment。API 使用 Bearer 令牌、精确 Origin/Host、JSON POST，不开放 CORS。根页面不含业务数据；CSP 禁止远程脚本与嵌入。令牌只用于本机服务访问，不是来源 API Key；重启服务须打开新链接。

HTTP 只开放生成的查询、同步、价表、配置、优化、授权、偏好、Codex 交接、账户和 timing 操作。请求和响应均验证。HTTP 使用 NDJSON 的 progress/result/error 信封，业务 DTO 不另行定义。输入上限为 64 KiB，响应上限为 16 MiB，最多八个并发请求，默认超时 120 秒。显式实时同步等待使用请求期限加 5 秒，传输上限为 605 秒；业务上限仍由生成协议校验。用量批量查询沿用同一宿主来源范围。断线中止对应调用；CLI 收到退出信号时关闭监听并取消自身请求。共享内核服务遵循[内核参考](core.md)中的生命周期，关闭 Web 不会停止常驻索引。关闭浏览器标签不会退出 CLI。

静态文件仅来自构建资产目录，启动时读取允许的文件类型，不提供目录浏览或源码访问。Node 与浏览器均保持有界输出，但这些上限不代表已验证百万级数据的内存目标。服务不支持局域网、远程或托管部署；没有通用文件写入、任意 shell 或内核 dispatch。

## Timing 读取

`/api/timing` 使用生成的 timing 协议。summary 和 evidence 请求必须显式提供本宿主已发布的快照身份；身份缺失或未发布时直接拒绝，不选择新视图。宿主拒绝浏览器传入 `roots`、`projectRoots` 和快照路径，复验目录授权后注入已授权来源根。Rust 验证来源、任务和轮次属于该精确版本。过期、撤销或淘汰均明确失败，不回退最新版本，也不恢复旧授权。

local summary 将 `readView.snapshotId` 发布到同一组最多 128 个身份中。share summary 不发布读取身份；share evidence 直接拒绝。配置读取视图身份仍独立保存。capabilities 不选择快照，也不读取目录授权。timing 不加载配置、项目工作目录、价表、hooks 或账户数据。请求取消也阻止迟到结果发布身份，其他读取者独立继续。
## 上下文打开

openView 使用 Rust 生成的 WebViewRequest，仅接受五页对应只读查询；在启动授权范围内读取真实结果并固定版本，返回有效上下文与会话链接。来源根不写入上下文，跨明确来源或未授权项目拒绝；无法映射的浏览器筛选也拒绝。日期、语言、对象和版本保持独立，浏览器采用自身分页大小。参数见 [CLI 指南](../guides/cli.md#codex-skill)。

## 后台补价

Web后台补价由宿主单一任务持有，基础用量先返回；必须注入 `createNodeClient({automaticPrices:false})` 以避免客户端原有阻塞补价。宿主 `automaticPrices:false` 关闭自动联网，`close()`取消并有界等待本宿主价表任务；Rust仍拥有资格/限流/版本。`restartCommand?`仅作为已认证来源页的复制材料；浏览器不能执行该命令或传入任意根路径。

## 验证

客户端构建后运行 `corepack pnpm --filter @wombat/web test`。测试仅使用临时合成目录和本机监听，覆盖认证、范围、进度、取消、并发与静态资源。`tests/timing.test.ts` 使用模拟客户端验证 timing 授权、分页、过期、分享和独立取消，不运行真实内核或浏览器。既有真实内核宿主链路在完整构建后的 `tests/e2e/web.test.ts` 验证，安装检查复用同一黑盒用例。

## 接入与采集

页头打开接入与 Skill 使用引导，不创建 Codex 任务。`/api/setup` 提供有时限的只读原生发现和 Hook 注册检查；`/api/collection` 提供生成协议的接收状态与事件操作，HTTP 不开放原始事件接收。宿主固定来源目录，检查所选项目，并在读取前重新确认目录授权。网页筛选不授予修改权限。

接入面板分开呈现偏好、原生发现、注册与信任、实际接收和当前历史视图。调用名来自实际发现；多个实例保留歧义状态。事件详情展开后读取，独立分页，在关闭或切换范围时取消请求。中文与英文共用这些状态，来源身份与事件类型不翻译。面板提供明确的 CLI 命令以修改本机偏好，不在网页执行命令。关闭 Web 不代表采集停止。

需要认证的 `/api/monitor` 路由复用类型化客户端；检查只接受当前宿主已观察的快照，验证所选项目和来源身份，并在计算前复查授权。Web 的监控请求不接受来源根路径。统计面板沿用用量路由；存储和提醒规则由[核心监控](core.md)拥有。
