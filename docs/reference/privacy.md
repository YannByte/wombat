# 隐私与本地数据

中文 | [English](privacy.en.md)

本页说明当前隐私边界；数据目录与存储机制见[内核说明](core.md)。

Wombat 无需 API Key，只读本地 Codex rollout 日志和标题索引，不修改 Codex 日志、配置、登录和安装。实时查询发现符合条件的用量缺价时，默认向固定的 OpenAI 官方地址下载价表；显式 `prices update` 也会联网。请求不携带本地日志、标题、路径、用量或凭据，但服务方可看到连接 IP 和 Wombat User-Agent；下载拒绝重定向并限制超时与响应大小。

设置 `WOMBAT_AUTO_PRICES=0` 关闭自动联网；`--cached`、固定快照及基础 `refresh` 不自动下载价表。显式 `prices update` 不受该开关限制。失败保留用量与价表，冷却及生效规则见[价格说明](pricing.md)。安装依赖所需的公共软件下载与产品查询分开。受管安装可以注册当前用户自动启动，并在后台准备近期日志。常驻索引仅在本地执行，不调用模型；自动价格联网仍沿用原有的查询规则。启动服务不会启用 Hooks 或改变原生信任状态。

派生索引与快照保留 Token 分类、价格依据、来源/对话/轮次身份、模型与推理强度、时间、项目、原生标题，以及安全操作字段（工具名称、文件路径、退出码、耗时、MCP server/tool）。确定调用请求的匹配摘要可保留，但不保存原始参数；它不能证明相同内容或效果。原始用户消息、模型正文、完整命令参数和工具输出不进入快照或普通元数据响应。显式对话读取可从选定授权视图返回有界、受支持的原文；原文检索读取选定文本，只返回位置。索引保留文本块位置及校验值、逐文件物理身份，不保留正文或媒体。这些指纹校验选定块，不是整个文件的内容版本。模型、标题、路径和名称仍可能包含敏感信息，不应随意外发。

运行复核可在内存中临时检查有界受支持的命令、提示与工具输出字段，识别风险模式；仅保留有限风险标签、问题 ID 摘要、原生调用/进程关联、响应存在标记和必要词法路径。不保存匹配到的凭据、掩码凭据、问题、答案、命令或输出正文。问题 ID 摘要只标识来源 ID，不标识正文；未知或过大字段保留明确覆盖缺口。

产品数据位于系统应用数据目录，可用 WOMBAT_DATA_HOME 指定。文件原子替换；Unix 创建私有权限，Windows 继承数据目录 ACL，应使用当前用户的私有目录。快照不是加密保险库。基础扫描不上传数据、不回放全文或提供任意执行。用户显式发送给 Codex 时，交接必要目标、工作目录、规则与证据版本；Codex 管理后续模型请求、执行及恢复，见[交接指南](../guides/cli.md)。账户读取不复制凭据。

来源目录会持续变化，单次刷新固定每个文件观察到的边界；部分失败、未完成尾行和无法确认的关联保留状态。工具调用没有独占Token时不伪造费用。官方 API 等价金额不代表订阅账单。

测试与公开仓库只使用合成语料。真实来源自测输出必须在仓库外，未经审查的 raw、真实对话与密钥不得写入测试或公开资料。历史用户决定、身份登记和恢复材料不随废弃功能清理删除。

授权根的配置全文仅在内存中读取、哈希和测量；派生配置缓存只存安全元数据。忽略/人工处理记录与语言偏好独立存于 user-v1，不随索引重建清除；记录仍含对象名称和路径，外发由用户决定。
