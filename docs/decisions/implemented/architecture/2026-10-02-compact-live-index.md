# 决策记录：紧凑实时索引与替换算法

中文 | [English](2026-10-02-compact-live-index.en.md)

Status: implemented

旧格式兼容决定已由[未发布首版仅维护当前格式](2026-10-03-current-format-only.md)替代。

下述逐行引用布局及页缓存选择已成为历史方案，由[有界压缩事实](2026-10-11-packed-live-index.md)部分替代；其余共享和事务理由继续适用。

## 问题

旧索引每条安全事实重复保存scope文本及JSON编码的字段/身份键；解析候选与提交投影均需要恢复，重复键开销随记录数增长。整字段替换构造完整编码键集合、再复制全部旧键；初次大事务留下的WAL文件也可能在后续小追加中维持峰值大小。

## 决定

当前 live-v2 目录内的 SQLite 独立使用 user_version=4；事件升级前的 live-v1/版本3保留但不混读。buckets字典按(scope,field)唯一分配整数；entries使用(bucket,id)复合主键和WITHOUT ROWID，每条事实不再重复范围/字段文本或JSON键。载荷通过SQLite自身jsonb编码、json解码，作为数据库内部不透明BLOB；公共DTO、当前快照和来源适配分别管理版本。JSONB是体积优化，不声称字段访问为常量时间，见[SQLite官方说明](https://www.sqlite.org/json1.html#jsonb)。

相同计量/操作的查询投影通过source_bucket与固定成员路径引用解析事实，只保留一份JSONB载荷；存在差异的累计归并结果仍单独保存。适配器在写入前逐值核对，按字段准备一次目标位置，单条插入同时确认来源载荷，更新、删除与游标处于同一事务。读取在同一SQLite视图中解析一层引用，缺失目标报错；已发布内存版本保持不可变。仅维护当前布局，不迁移旧索引。

字段替换使用借用身份的HashSet，逐行查询现有身份，只复制需删除的身份，完成读取后才删除。不一边扫描同表一边修改；相同载荷不重写。追加仍仅写脏计量、操作和游标，不改为逐次VACUUM或整库重写。

不可变计价事实回灌解析缓存时，三个身份有序序列采用归并游标，先检查共享指针、仅在值相等时复用。替代逐行BTreeMap查找和投影二分搜索，单来源额外工作为线性遍历且不分配新集合；不同值的更正、缺失身份和其他来源不覆盖。多来源仍分别经过全局计量序列，不宣称局部追加已与全历史规模无关。

同一价表下，计价构建最多记忆4,096组输入，按模型、Token各项及requestScoped哈希筛选并逐值复核；只共享不可变计价结果，不合并计量身份或减少账本。缺失与零、不同条件及金额保持独立。超过预算照常计价，结束构建即释放候选池；落盘JSON结构不变。脏身份暂存集合在写入后清空，不跨读取保留。

计量与操作内部的来源、任务/轮次、模型和状态等重复字段使用Arc<str>。扫描及实时索引恢复按完整文本相等共享，不合并事实身份；每个池最多4,096项、1MiB文本，单项超过1KiB不入池，另有有限表项开销。预算用完保留原值，并继续复用已收录文本，不截断字段或丢记录。解析缓存的池随缓存保留，投影恢复的临时池在读取结束后释放；已共享事实不为压缩而复制。新版本修改仍写时复制，不改变旧视图。该优化不缓存正文、不增加依赖，也不改变JSON字符串、Schema或数据库布局；内容各异的事实和计价仍有独立成本。

不同请求的总价不同，也可能包含相同计价分项。分项使用Arc按类别、数量、金额、状态和费率逐值共享；池最多4,096项及1MiB分项文本，单项文本超过1KiB不入池，另有有限结构和表项开销。价格描述文本使用独立池，复用与事实相同的有界文本共享实现。超预算继续独立保留，已发布分项不因压缩而复制；完整请求的计数和金额不合并。汇总按四个类别流式累加，取消随输入条数增长的分项引用列表及费率集合；不同依据、问题和价格版本仍需各自集合，不宣称整个汇总空间恒定。总额及分项同时校验状态与精确金额，单条查询也校验后保留原请求依据。

每连接设置4MiB页缓存目标、文件临时存储、512页自动检查点和8MiB日志保留目标；保持WAL、FULL同步和原提交事务。日志目标不是硬空间上限：大事务、活跃读者和检查点失败可能暂时扩大WAL。页缓存预算也不是进程峰值内存上限，内存事实/版本另有成本。

2026-10-03按未发布首版移除旧kv迁移及压实分支；仅空数据库初始化当前布局。未知布局或版本明确拒绝，已有数据不删除。用户处理记录和不可变快照由各自存储管理。

## 考虑过的方案

继续使用文本kv并仅限制WAL只能减少日志保留，无法消除逐行重复键。为每个小记录引入通用压缩会增加编解码成本与依赖，本次先复用已锁定SQLite。当前已进一步共享相同候选/投影；不同派生值继续分开。完整数据库聚合及快照内容寻址会影响固定版本和读取成本，仍需单独验证。

## 影响与验证

当前回归覆盖当前布局重启、最大整数和极小浮点值、Unicode、未知布局/版本拒绝且不丢数据、空映射/标量、字段/来源隔离、替换删除、相同值不写和损坏载荷报错；CLI验证缓存版本、游标追加、固定查询和快照导出。

release固定语料分别记录冷/热查询、追加、峰值RSS、数据库/WAL及闲置退出后磁盘；结果与限制见 Git 历史中的验证记录。相同事实不再重复保存，内存仍按历史规模增长；百万级、长期驻留、其他平台和真实来源未因此完成验收。
