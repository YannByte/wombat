# 决策记录：一个任务主 Skill 与本地 CLI

中文 | [English](2026-10-31-cli-task-skill.en.md)

Status: implemented

## 问题

分散的任务 Skill、Web 启动和浏览器专用交付重复了用户路径。诊断可能在读取相关工程证据之前花费时间准备环境。

## 决定

交付一个 Wombat 主 Skill，按需加载接续、排查、交付核对、阶段复盘和工程改善五类任务流程。准确事实和有界历史检索复用现有生成的 CLI 契约。静态项目检查直接使用 Codex 文件工具，没有初始化阶段。计量、价格、范围和版本规则保留在内核。

移除 Web、UI、HTTP 传输、浏览器专用 Schema、构建资产和验收阶段。不增加旧命令别名或格式迁移。保留 CLI 消费者使用的本地查询服务、可选采集、预算、原生交接、用户决定和原问题复查。

诊断首批聚焦指令与实际入口不一致、普通交付绕过已有检查，以及失败缺少有界处理或恢复路径。建议需要已观察后果或确定性缺陷、具体负责位置、最小行动和原问题验证。不要求建议数量、总分或固定模型角色流水线。

不建立第二套任务数据库或自动分析记录。现有证据身份和配置处理记录服务现有消费者。语义工作关联保留为经过审阅的解释。普通查询不保存诊断。选定跟进通过已有检查记录或获授权的项目笔记，保留原始范围、目标版本、证据和成功条件。静态修复、后续采用和效果改善分别报告。

## 考虑过的方案

保留 Web 或四个任务 Skill 会延续重复维护。新增通用任务模型或自主诊断服务会在缺少实际 CLI 消费者时增加状态。照搬固定多角色评分流程会提高简单问题的取证与模型成本。

## 影响与验证

源码检查禁止恢复已移除的交付依赖，并约束只交付一个 Skill。产品测试使用真实本地客户端和组装后的 CLI，以独立合成数据验证计量。真实来源验收使用冻结的只读语料、独立空产品目录及改动前后相同查询。功能结果和不完整覆盖结果保存在仓库外，本次不验收性能指标。这些检查不证明因果节省或后续采用。
