# 决策记录：实时索引的有界压缩事实

[English](2026-10-11-packed-live-index.en.md) | 中文

Status: implemented

## 问题

原有逐行布局重复保存观察封装，并为每个事件保存一条投影引用。解析器中的计量和操作副本不参与恢复：现有重放已经能从观察恢复这些事实。移除副本可减少持久化数据，同时保持计量语义。逐条压缩无法充分利用重复的来源、任务和结构字段。

## 决定

保留 SQLite 事务，使用锁定版本的 Zstandard 库对相关事实分块压缩。保留足以支持离线重放的安全观察，移除重复的解析投影和逐事件引用行。当前格式、边界及恢复行为由[内核参考](../../../reference/core.md)维护。本决定部分替代[紧凑索引决定](2026-10-02-compact-live-index.md)中的逐行引用布局和页缓存选择；原有身份、精确值共享、只支持当前格式和原子发布的理由继续适用。

按来源文件划分窗口，限定追加时需要重写的范围。精确目标块允许使用原生 SQLite 表达式索引取代重复的任务成员表，写块时不再维护或扫描第二份表示。规范查询事实单独保存在有界块中，查询与恢复可以取得计量事实，而不必解码观察块。小批追加复用当前事实块。读取校验摘要、解码大小上限、明确的编解码版本和身份。块、成员、检查点和视图沿用同一事务边界。用户决定和采集历史保留在各自独立存储中。

本次保留无损安全证据，不切换为只保存来源定位。来源被移除后，已有计量和分析仍须能够恢复。只依赖来源的方案需要独立的可用性约定和经过校验的来源代次。本次不向索引加入对话或工具输出正文。

由规范事实和紧凑证据元数据恢复一次已准备视图。固定现有 SQLite 版本，避免在内存中重新构建事件封装；各项目加载进度共享准备结果，包括不可变的任务、轮次及事件分区元数据。操作恢复为经过校验的块定位和使用计数，仅在请求明细时解码完整记录。首次扫描分批写入观察。仅对最小业务输入做临时磁盘排序以恢复计量顺序，并按任务和轮次逐个归约关联图。直接观察与顺序重放复用同一计量归约，完整事件封装及操作明细不进入该排序。保留规范分量和身份锚点，释放原始阶段记录；保留全局身份冲突顺序，追加只刷新受影响范围。这会占用临时磁盘，规范来源状态仍驻留内存。事务内块元数据复用已校验写入中的事实，避免为了索引再次解码明细；不新增第二份持久表示。追加归约复用未受影响的目标分区，避免解码整份归档。目标连接使用 [SQLite 连接顺序控制](https://sqlite.org/optoverview.html#manual_control_of_query_plans_using_cross_join)及现有表达式索引。虚拟目标列表没有持久基数统计；按目标驱动查找，避免目标和块的处理次数相乘，不增加持久索引。证据保持无损，来源移除后仍可读取，并只解码选定块。代价是少量定位元数据，以及固定视图仍被保留时可能持续占用的 WAL 页。当前限制及释放行为由内核参考维护。

规范事实事务内持久保存块内充分统计。新计量块按任务、模型、推理强度及时间戳小时聚集。跨轮次聚合，并为每个轮次保留有界的精确槽位成员；按轮次保存聚合会接近计量基数，重复计价封装。匹配轮次的去重保存在独立的可转存关系中，避免任务记录不断增长。更正时重算受影响块，避免自行实现最小值、最大值、去重集合及价格的逆运算。此方式支持精确范围，不物化所有时区和筛选组合。UTC 小时分组使用精确本地日期；时区边界将同组拆到不同日期时，只读取有界的规范成员。按字节预算优先保留最近访问的聚合，因为日期本身无法限制高密度用量。历史留在磁盘，不缩小结果范围，也不丢弃离线证据。查询归约的内存预算用满后，转存私有 SQLite 临时存储。限制昂贵并发查询，在固定视图内复用已完成的重复请求。限制由内核参考维护；解析驻留和严格请求延迟仍需独立验收。

Unix 服务连接改为等待套接字就绪，取消周期轮询引入的额外前台等待，并减少空闲唤醒。不改变查询新鲜度、同步及取消约定。

## 考虑过的方案

[存储实验](../../../benchmarks/storage-layout-2026-10-11.json)比较了 SQLite 和 DuckDB 保存压缩安全观察的方案。DuckDB 在实验中加快了大范围事实扫描，但总占用更大，并引入第二种引擎；SQLite 可复用现有事务和部署边界。只保留聚合会丢失精确更正及已有证据能力。只依赖来源的存储具有不同的离线保证。[实时用量方案](../../proposed/architecture/2026-09-30-live-usage.md)继续维护未完成的驻留、聚合规模和延迟验收；压缩存储本身不能证明这些目标已达成。

## 影响与验证

存储格式独立于公共 DTO 和来源映射变化。未知或旧布局被拒绝并保留，本次不迁移或删除旧数据。块压缩增加 CPU 工作和原生依赖打包成本。更正重写对应块，未变化块保持原字节。SQLite WAL 和临时空间峰值与稳定数据库大小分开统计。

Rust 回归覆盖精确数字与空值、小批追加合块、更正、撤回、缺失或损坏块、只读筛选、来源移除后的重放、重启及事务回滚。[生产基准](../../../benchmarks/production-storage-2026-10-11.json)通过真实 CLI 校验独立的 Token 与金额、任务和每日合计、快照导出、重启及重建。平台、语料、缓存和内存限制由各基准结果说明。显式校验与来源替换的驻留、关联状态、聚合规模和严格请求延迟仍需方案中的后续设计。
