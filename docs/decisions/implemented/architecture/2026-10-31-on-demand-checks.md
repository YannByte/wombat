# 决策记录：只读检查与单插件

中文 | [English](2026-10-31-on-demand-checks.en.md)

Status: implemented

## 问题

任务发送、持久化检查观察、采用跟踪与多种安装方式重复了 Codex 的职责。未实现规则和默认可选探测掩盖了可行动证据。

## 决定

只交付一个主 Skill 和一个插件。Codex 负责解释、授权编辑、任务与恢复；Wombat 提供有界事实、已实现检查和显式用户决定。复查使用保留的原视图与绑定范围/规则的基线 ID；视图过期重新检查，不重建历史或推断采用。保留现行决定格式与有效身份，不做迁移；移除自动写入和历史展示。记账链路保持不变。

本决策替代[原生交接决策](2026-10-03-native-codex-handoff.md)、[优化提案](../../proposed/product/2026-10-03-optimization-lifecycle.md)和 [Skill 提案](../../proposed/product/2026-10-04-codex-skill.md)中 Wombat 负责发送任务、自动检查历史与采用跟踪的部分。来源只读、证据与原生执行归属的理由继续有效；其他未完成证据要求仍为提案，不是已交付能力。

## 考虑过的方案

保留生命周期和多种安装方式会保留更多状态与歧义。只返回当前检查会失去原比较条件。保留视图的基线无需新增持久化存储即可固定该条件，代价是明确过期，而非作出无依据的修复声明。

## 影响与验证

检查不再积累自动处理记录；用户决定继续使用现行存储格式 4。原视图过期需要重新检查，不能事后补造可比较基线。默认 setup 无需可选 Hooks，独立请求才读取注册证据。未知版本拒绝且保留数据，没有迁移或旧接口别名。

[内核用例](../../../../core/src/optimize/tests/stateless.rs)验证只读、范围绑定、过期、不可比较和用户决定；[真实流程](../../../../tests/e2e/static-rules.test.ts)验证原条件复查与关系证据缺口；[交付检查](../../../../scripts/check-delivery.test.ts)阻止已移除宿主、安装入口与采集插件重新进入。生成契约、完整产品测试和 macOS arm64 的全新安装、原生发现、升级验证均通过。固定真实来源的用量与任务统计逐字段一致。Windows、Linux 与完整模型建议质量未在本轮重新验证。
