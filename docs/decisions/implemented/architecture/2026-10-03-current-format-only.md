# 决策记录：未发布首版只维护当前格式

中文 | [English](2026-10-03-current-format-only.en.md)

Status: implemented

## 问题

作出此决定时，产品尚未发布。旧快照读取、数据库迁移、旧身份映射、旧页面链接及旧生成协议增加维护分支和资源成本。用户要求不做兼容逻辑，并保持代码干净。

取代[快照旧格式](2026-09-30-snapshot-storage.md)、[索引迁移](2026-10-02-compact-live-index.md)及[处理记录迁移](2026-10-02-rule-review-integrity.md)中的兼容决定。

## 决定

仅维护当前快照、数据库布局、生成协议和页面路由。删除旧快照读取/金额政策、索引及处理记录迁移、身份登记映射、旧页面参数与整批生成分支。当前物理对象身份用于操作，逐来源上下文仍用于证据归属。

未知布局或版本明确拒绝，保留原数据；不自动转换、清空或假装空记录。当前格式中的不可变历史、用量、处理依据和恢复材料继续保留。来源自身的累计计量与逐响应事实属于真实日志适配，继续解析。

## 考虑过的方案

保留旧格式只读及事务迁移会继续增加分支与验证负担，因此在当时的未发布阶段未采用。直接清空不支持的数据会丢失记录，也未采用。

## 影响与验证

开发阶段的旧布局可能无法读取。每次发行仍需核验当前版本的干净安装和完整旅程。当前格式与恢复行为见[核心参考](../../../reference/core.md)，验证要求见[开发流程](../../../development/workflow.md)。实际运行证据保留在任务、CI 或验证工具产物中，不以历史测试或构建代替当前验收。
