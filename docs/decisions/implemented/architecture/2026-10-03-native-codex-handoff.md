# 决策记录：简化本机Codex交接与独立账户读取

中文 | [English](2026-10-03-native-codex-handoff.en.md)

Status: implemented

当前精简范围替代本页的任务发送、多安装模式、自动检查历史与采用跟踪；保留其余证据约束和未完成事项。见[只读检查与单插件](2026-10-31-on-demand-checks.md)。

## 问题

Wombat需要将确定性建议交给本机Codex，用户明确要求重复发送影响不大、对接保持简单，并用重新检测判断解决。重做方案、执行、恢复和持久任务查重会形成第二套执行系统；账户事实又不能由项目用量或固定额度周期推断。

## 决定

Rust组织当前授权范围内全部符合条件的待处理项，合并共享物理文件和同文件规则，按项目cwd形成版本绑定清单。CLI/Web先preview再确认send，发送前重新校验文件和依据。Node只调用固定原生方法：启动Codex自有后台宿主、创建持久任务及入队请求；不使用开发会话协作工具。接受与实际解决分别显示。

仅发送期间阻止重复点击，不遍历历史任务、保存任务关联或加跨进程锁，不维护Wombat执行回执。原生消息编号内部生成，不进入产品参数。送达不明先查看Codex，用户可再次确认后重发；重复发送可能创建新任务。断开Wombat只清理自身连接，不取消Codex已接受任务。

账户通过独立原生读取取得身份、额度及活动，再由Rust归一化；不读取或复制凭据。仅使用当前多桶字段及实际窗口，不回退旧单桶或固定五小时/七天。各分区保留自身读取时间，失败保留陈旧事实，换账户丢弃旧信息；超过安全整数和无效重置保留未知，不推断普通使用限制或额度恢复。

余额、消费限额与重置权益保持各自原生单位和状态；权益只读。异常字段保留合法同级事实并公开partial；数量、未知明细和空列表分开，不以截断后的明细重算来源总数。概览与账户窗口共享观察，语言、项目和日期不触发独立额度请求。具体字段和上限见[账户契约](../../../development/contracts.md)。

额度判定只使用原生明确限制的请求模型，不根据normalModelSlug展示信息或百分比猜测适用桶。上游[协议定义](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/protocol.rs)和[原生通知处理](https://github.com/openai/codex/blob/main/codex-rs/tui/src/chatwidget/backend_banners.rs)区分展示模型与blocked_model_slug。预览查询限制时长及数量，失败不阻止本地审阅；发送以实际任务模型重新读取并复核文件。60秒观察期限只约束新鲜度，不代表恢复时间；详情见[契约](../../../development/contracts.md)。代价是最后判定受阻时可能保留空任务，避免Wombat再承担任务删除和恢复。

## 考虑过的方案

持久化任务关联、历史遍历和跨进程锁曾用于查重调查；用户确认收益有限后移除。Wombat自有方案、应用及恢复链路已退出职责。直接依赖短命子进程承载任务不能确保页面关闭后继续，当前使用Codex自有持久宿主。

## 影响与验证

原生接口当前在本机macOS arm64的Codex0.160.0核验；其他版本/平台需独立验证，异常接口明确失败。Web通过启动授权范围限制目标，通用客户端不开放任意RPC；进程有取消、超时、输出上限及清理。新增固定版本WebSocket依赖及许可材料，普通用量路径按需加载原生模块。

隔离合成项目验证原生接受和断开后任务保留；合成HTTP验证全部待处理选择、共享目标、跨项目选择失效及内容变更拒绝。账户故障验证旧读取时间、换账户清理及无凭据输出；原生协议验证拆分UTF-8、异常响应、拒绝脱敏、超时、取消及失联。完整升级与平台边界仍见[未完成提案](../../proposed/product/2026-10-03-optimization-lifecycle.md)，实际本轮证据见 Git 历史中的验证记录。
