# 决策记录：报表默认日期随粒度变化

中文 | [English](2026-09-30-report-ranges.en.md)

Status: implemented

当前查询范围见[CLI 指南](../../../guides/cli.md)，Web 导航见[前端说明](../../../development/architecture.md)。本记录保留共享默认日期的理由，不维护退役终端行为。

## 问题

近7天原先应用于全部分组，终端又将响应日期写回请求，导致周报和月报仅汇总最近一周。

## 决定

日期默认值由共享内核按日报、周报、月报分别解析，采用有限的多个周期并截止当前时区的今天；具体范围由[CLI 指南](../../../guides/cli.md)维护。显式日期和完整对话、未知日期筛选优先。隐式日期不能被响应中的解析结果永久写回为显式条件。

## 考虑过的方案

只看本周/本月不便比较上期，默认全部历史扩大日常查询范围，因此采用有限的多个周期。仅在界面计算会与CLI口径不同，故日期算法由内核负责。

## 影响与验证

此选择只改变未指定日期请求的默认范围，不截断采集或改变固定快照。验证需覆盖时区日期边界、显式日期优先、共享 CLI 查询与当前 Web 日期意图；历史终端测试不能证明当前 Web 行为。
