# 决策记录：项目级渐进初始化与故障验收

中文 | [English](2026-10-02-progressive-initialization.en.md)

Status: rejected — mandatory initialization and browser flow removed

此方案已由[CLI 与任务主 Skill 决策](../../implemented/architecture/2026-10-31-cli-task-skill.md)取代。保留原始理由和验收设想作为历史，不再安排初始化或浏览器工作流。

## 问题

首次大历史读取可能尚无完整结果，现有临时任务视图不等于项目级进度。缺少真实项目事件、稳定项目/worktree 归属及单项目重试时，不能用文案或原型宣称完整初始化完成。本提案承接原启动规格的剩余 A5 验收和初始化设计，不重复已交付的 A1—A4 与静态 B 分支。

## 方案

当前来源发现、增量索引、恢复与提交由[内核说明](../../../reference/core.md)维护，当前 Web 查询生命周期由 [UI README](../../../development/architecture.md)维护，项目授权理由见[项目发现决定](../../implemented/architecture/2026-10-04-observed-project-discovery.md)。继续在现有流程上增加项目级读取事件、渐进提交、独立失败与重试，不能另建一次性导入状态或从是否点过按钮判断初始化完成。

### 真实事件与项目身份

事件至少需要读取周期/来源身份、可靠项目或工作目录身份与路径、等待/读取/已提交可用/失败状态、可打开任务或版本、覆盖缺口、取消范围和错误码。事件从现有扫描增量产生，不为计数再完整解析日志；读完一个文件不等于项目完成。多个项目可以同时读取，不从等待时间推断规模或百分比。

项目与 worktree 归属必须有可靠证据；同名显示目录，只有工作目录证据时按目录表达，不把 worktree 自动算作独立项目。仅创建文件夹不产生项目记录，不扫描全盘猜测项目，不执行项目文件。来源历史与当前配置读取保持不同语义。

### 渐进可用与交互

外壳先出现，连接、偏好和账户独立。首次无结果时显示“正在准备历史记录”和实际活动，尚无项目证据时显示“正在查找记录位置”。识别后展示稳定列表，以“等待整理”“正在整理”“可查看”或明确失败表达项目状态，不输出推测 ETA、百分比或逐文件日志。约1秒提示进行中、约10秒提示较久只是交互建议，不是性能承诺。

只有已提交可打开记录才能进入任务列表，未完成汇总明确“历史仍在读取，用量暂不完整”。后台完成不跳走正在看的内容；单项目失败不清空其他项目。单项目重试只重读失败对象，继续查看复用现有工作，不清空索引或无条件启动第二次扫描。

停止等待仅停止本页请求与跟进，不能冒充共享扫描取消。首次取消而没有已提交结果时明确无结果；多窗口不能相互取消。屏幕阅读器在识别数量、活动项目或可用状态改变时合并播报。

## 考虑过的方案

等全量历史完成再显示会阻塞已有可用结果。根据时间、文件数或设计样例伪造项目进度会将部分结果误报完整。独立导入流程重复索引生命周期，因此沿用当前服务和事务，只有真实事件足够时才开放项目级状态。

## 验收条件

项目级事件、提交、归属、失败展示和重试仍待实现及验证；当前通用读取状态和临时任务预览不代替它们。已交付行为的回归由现有模块测试承载；下列原 B01—B26 保留为尚需完整旅程证据的范围，不复制逐项通过状态。

| 编号 | 数据/操作 | 关键断言 |
|---|---|---|
| B01—B05 | 新数据目录；活跃+归档、仅旧历史、无日志、只有任务无计量、大历史取消 | 正常可读、归档不重账；日期空可查看全部；未知非零；pending与无记录不同，首次取消无旧结果 |
| B06—B10 | 错误/拒绝目录、未知格式、离线缺价、多根单源失败、组合筛选空 | 范围/能力/原因准确；Token不被补价阻断；健康来源与旧贡献准确；清筛选不改授权 |
| B11—B16 | 时区午夜/未知日期、多模型缺轮次、同名跨源与归档、未授权或删除配置、超限/编码、读取/MCP失败 | 分层守恒、身份和日期不猜；当前未知不解释历史；读取不当调用，失败尝试保留 |
| B17—B19 | 导入旧历史、无建议/全部忽略/检测不可用、人工修改后删除/方法变化 | 不造连续闲置；三类状态分开；用户决定/基线保留，证据不足不解决 |
| B20—B23 | 切范围迟到响应、多窗口一方取消、重启/失效版本、跨日偏好与手动日期 | 范围/版本隔离，不误取消；新链接恢复；相对日期滚动/固定日期不变；偏好失败不阻塞 |
| B24—B26 | 未知索引格式/写满、两语390px与键盘、同版本CLI/HTTP | 存储失败不成功、不删用户状态；操作与身份可达；数值/次数/建议一致 |

另覆盖宿主运行中新项目出现、直接打开其配置、同名目录、未归属记录、项目不可读和浏览器伪造路径拒绝。旧结果按范围/版本绑定，新结果不能覆盖用户选择；未知格式拒绝且保留数据，存储失败不回执成功。使用合成来源与仓库外目录，不读取真实对话。

分别测 URL 就绪、外壳、首个有效用量与各分区完成；记录 release、语料、缓存、平台、Rust/Node/浏览器内存及临时/稳定磁盘。历史 CLI 基准不能相加为 GUI ETA。百万级、服务 RSS 和24小时目标统一归[实时索引提案](../../proposed/architecture/2026-09-30-live-usage.md)，本提案不维护第二份指标。

## 风险

项目级提交可能与来源级归并、跨文件继承和单写事务冲突，须先证明计量守恒与版本一致性。项目事件和可访问记录必须同版本；取消、迟到响应、睡眠恢复和故障不得发布半份结果。静态页面、受控写满或本机测试不能证明真实磁盘故障、全部权限和目标平台通过。
