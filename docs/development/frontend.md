# Web 前端

中文 | [English](frontend.en.md)

`@wombat/ui` 是 React / TypeScript / Vite 展示模块。`App` 注入 `UsageClient`，浏览器入口装配 HTTP 和本次访问令牌。扫描、计价、汇总、分组与匹配排序由 Rust 提供，不迁移旧 TUI 页面。

## 运行

从仓库根目录构建并启动：

```sh
corepack pnpm build
node dist/wombat.js web --lang zh
```

打开输出链接；页面读取本机记录，Ctrl+C 停止服务。可用 `--root` 指定来源、`--port` 指定端口。服务只监听 loopback，访问令牌留在当前浏览器会话，重启服务后需要新链接。

## 页面与实现边界

| 页面 | 已接入 | 明确边界 |
|---|---|---|
| 外壳 | 目录范围 × 概览 / 任务 / 指令 / 扩展 / 优化；深浅主题、中英切换、窄屏导航；桌面侧栏常驻账户级额度摘要，窄屏顶部单一入口 | 账户额度不随项目或日期改变；未知、过期和多窗口不合成为0%或单一比例；历史目录证据不等于项目注册 |
| 概览 | Token 与金额同屏、缓存命中率、时段趋势、目录/模型排行、统一右侧详情、近期/高用量任务与优化摘要 | 未知不作零；金额为标准 API 等价估算 |
| 任务 | 用途说明、当前筛选的任务/Token/API估算汇总；标题/目录/完整 ID 搜索，明确关联轮次数、相关建议标记、匹配消耗/最近匹配排序、分页、ID 定位及最近/全部/最高用量轮次入口 | 轮次数只来自当前列表范围中有明确关联的记录；缺失显示未知，建议只在既有证据可关联时显示；不展示完整对话正文 |
| 轮次 | 全对话/匹配用量、历史模型与强度、执行状态及原生/派生耗时、内核相对时间轴或列表降级、固定版本证据与安全分享预览 | 没有轮次关联的计量单列，不猜测操作费用；Skill/MCP 使用总计、对象页及操作证据固定同一快照，全轮未知次数与已关联次数分列 |
| 来源 | 实际来源身份、目录、能力、覆盖状态与问题 | 不宣称连接健康，不修改来源配置 |
| 金额依据与价表 | 历史计价版本、类别费用、官方来源、标准/长上下文档和真实更新 | 价表页展示当前价表；固定快照不随更新重算 |
| 配置 | 类型/证据/搜索筛选、完整汇总、详情、固定版本证据分页、配置与回合双向跳转、跨目录关联 | 历史中已观察项目可直接切换读取，额外目录由宿主添加；历史版本未知、覆盖缺口均明确；完整内容按固定方法估算 Token，码点/字节和历史次数独立 |
| 优化 | 对象级静态建议、待处理/记录、保留/不适用、重新显示及直接复查；详情按问题、位置与证据、建议处理、关联用量、计算口径、处理记录阅读 | 格式问题公开文件与行列、字段、原因和安全的结构示例，不保存字段原值；决定与逐规则检查事实独立，不预测节省 |

页面结构按已审查的 HTML/CSS 与渲染函数改写成 React；[样式](../../ui/src/reference.css)保持原始字节，布局适配单列在 `style.css`。必要视觉资产与哈希见[清单](../../ui/reference-manifest.json)。构建和测试不依赖外部设计仓库，也不打包演示数据或模拟配置操作。

设计取舍与有意保留的差异见[本地 Web 决策](../decisions/implemented/architecture/2026-10-01-local-web.md)。

概览中的“使用分析”按需读取检查任务、资源热点、上下文记录或周期复盘；任务详情按需读取输入变化轨迹及独立的压缩前后对照。复盘展示核心返回的集中度与剩余任务用量。各查询保留当前视图和范围；复盘在全部/未知日期范围下选择截止日期所在周，并明确显示实际日期。阈值、分组、排序、覆盖及预算均由核心返回，页面不计算业务规则。证据跳转保留原范围、完整身份及快照；操作证据自动打开并定位记录页，过期提示重新取得范围。账户弹窗可独立读取额度观测历史，不触发原生刷新；保存失败和历史读取失败分别显示。统计限制见[核心参考](../reference/core.md)。

使用分析还展示重复慢请求、历史失败率/耗时上升、跨任务重复流程，以及同一任务反复失败或被拒绝的请求。同一请求的多个信号合并展示，直接给出改进建议；本期与历史期证据分别保留各自日期范围和同一快照。完整命中组数、请求匹配覆盖和历史日期同时显示；具体阈值与统计归[核心参考](../reference/core.md)。

## 内部职责

概览、任务与相关配置共用内部返回路径，保留每一层的筛选、轮次及操作记录分页。`navigation.ts` 和 `useNavigation.ts` 管理浏览位置：内存最多保留 24 个视图，当前历史项保存有界滚动、展开与焦点信息，刷新可恢复当前位置。恢复等待异步内容到达，用户操作立即优先；不保存对话正文。该机制不将用量弹窗保存为跨页业务记录。

`App`装配路由与共享上下文；`shell/`负责导航、日期/筛选和来源；`config/`负责证据详情及测量标签；`optimize/`负责建议详情与规则依据。查询生命周期保留在对应Hook，业务规则与用户记录持久化仍在Rust；页面仅使用当前路由和独立筛选状态。

## 状态与查询

日期包含首尾两天，调用时转换为排他结束边界；全部包含日期未知记录并标注；切日/周/月不改日期。全部输入包含缓存读写，推理是输出子集，保持旧 `tokens.input` 的非缓存含义。新派生值及目录/模型分组来自生成契约；CLI 提供相同查询。

URL 保存范围、筛选、搜索、排序、趋势/对话/轮次分页及选择，浏览器前进/后退恢复状态。页面可见时，每次查询完成后约3秒探测当前版本；版本未变不重读列表，隐藏时暂停，重新可见时补查。阅读对话或展开时段明细时保留当前版本，只提示新数据，由用户应用；应用更新保留同范围明细展开和分页。同步未完成或失败会显示旧结果状态并继续重试；主动取消暂停自动跟进，切换查询或重试后恢复。连接凭据失效则停止探测，提示从终端打开最新完整链接。空页面区分未发现日志、来源读取不完整和筛选无匹配，并提供来源、清除筛选及可用日期入口。

轮次执行面板使用与耗时汇总相同的固定快照、来源、任务和轮次查询活动检查。建议先显示具体次数或已记录比例、下一步和证据入口，与 CLI 复用共享文案；展开后可查看全部五个检查及阈值、样本与依据限制，失败占比同时显示结果可判定的样本数、失败数和明确阈值；样本较少时解释原因并保留统计。证据按钮打开现有整轮记录集合。用量调查和复盘候选按内核已返回的信号展示实测值和对应下一步，缺失值仍为未知，不在界面重新判断阈值。离开所选轮次会取消读取并丢弃迟到结果。版本过期时保留原事实并禁用证据操作；局部读取失败可重试。模拟预览使用此生产组件及模拟客户端响应。

主列表和趋势先固定到同一版本再更新；轮次执行过程以外的版本过期会重读一次并提示。轮次执行过程保留旧组，过期后要求显式整组刷新。查询缓存最多16项，仅保留一个版本。轮次默认只看匹配计量，可切换完整上下文并定位原轮次；每页20项，事件每页100项；趋势每页120个时段，时段明细展开后按12个时段分页，模型/强度明细只读取展开的时段。汇总、排序和图表刻度来自完整范围，不从当前页重算；不再遍历全部分页。单个时段的明细仍按内核完整组返回，并受宿主响应上限约束。

失败/取消保留上次完整主视图，同范围旧结果可继续下钻；前一范围结果不能当作新范围继续操作，局部明细失败可独立重试。明细按版本、范围、选择和页码识别，过时响应不能覆盖新查询；范围变化重置明细页。浏览器刷新保留 URL，重新读取版本；主题留在本机浏览器，不持久化结果或完整对话。时段明细和事件分页在组件内，不跨刷新恢复。

## 开发与验证

UI/Web 手写 TypeScript 用锁定的 Prettier：`corepack pnpm format:write` 格式化，`corepack pnpm format:check` 只读检查，纳入 `repo:check`。契约由生成器维护。

只依赖客户端公开接口和语言服务，不导入 Node、Tauri、终端或原始来源。静态资产由完整构建复制到 `dist/web/`；修改后重新构建并重启服务。桌面宿主尚未交付，见[架构](architecture.md)。

`corepack pnpm --filter @wombat/ui test` 验证 URL 往返、日期转换、固定版本传输、自动版本跟进、范围失效、过时响应、过期恢复、取消和隐藏暂停；跨语言真值与主链路由集成/端到端测试覆盖。浏览器验收范围及未验收平台见 Git 历史中的验证记录。构建、静态检查不替代真实交互或逐像素比较。

配置路由保存类型、搜索、证据状态、排序、页码、选中项和读取版本；离开或改变查询会取消当前连接并隔离迟到结果。配置页不轮询，显式刷新更新配置与用量；过期提示重新读取。原回合跳转固定其用量版本，返回保留配置位置。配置特有布局在 `src/config.css`，实际范围见[配置契约](contracts.md)。

用量或金额打开同一右侧详情，按时间/模型/项目/相关任务查询固定用量版本；概览金额两位，详情四位，正值低于精度显示阈值。任务列表汇总沿用当前搜索与全局筛选的内核结果，不从当前分页重算；列表轮次数按匹配计量中的明确轮次 ID 去重，来源未提供关联时不显示0。任务构成默认展开、来源折叠；最近、全部、最高用量轮次和已有相关建议位于任务总量下方，按固定版本定位。390px 窄屏先显示列表，进入详情后可返回并保留范围与选择。语言切换保留弹窗和焦点，偏好经 Rust 保存到产品数据目录。

优化按对象合并问题，URL 保留类别、pending/history、建议与独立记录身份、读取版本及决策版本。详情先显示问题与可操作证据，格式诊断给出文件、行列、字段、错误原因，以及不含字段原值的当前结构和正确格式；规则版本、阈值和计算方法折叠显示。主要界面不提供单项或批量派发按钮；页头「配合 Skill 使用」提供实际调用方式和提问示例。查看证据后，在当前 Codex 对话中审阅并处理对象，再回到页面复查。复制路径仍可辅助定位；首次观察保存原始依据。共用评估组件展示五种检查结果，包括未发现问题时的测量和阈值，并说明证据缺口与原始范围。复查直接消费内核明确的可比／不可比／未知状态，不从当前文件值判定解决。用户决定及原因与本次事实和不可变基线分开展示。Skill/MCP 关联使用次数来自内核投影；零、未知次数、失败操作和完整范围总量均与分页证据区分。无法读取或完整解析时保留原问题，不显示通过。保留/不适用及原因与检查结果分别保存，复查不撤销决定，记录不随派生索引重建丢失。无闲置和空间适配的类别直接说明不可检查。

首次外壳先渲染，再异步恢复偏好；用户选择优先。SYNC_PENDING显示本页等待秒数并自动跟进，取消不宣称停止共享扫描。来源页可在无首个结果时读取启动授权；有任务元数据但无计量时可扩大日期/模型条件进入任务列表。默认近30天保存相对意图，手动日期与固定版本不滚动。

时间趋势仅绘日期已知记录；全部日期总量仍含未知日期，未知日期另有用量详情入口。更新失败时，就近标示上次成功读取时间，原范围/结果保留，范围变更未就绪时仍禁止旧结果冒充新查询。当前共享配置详情按来源展开证据；任务的关联配置与用量详情分别布局并可换行。

## 共用组件预览

运行 `corepack pnpm --filter @wombat/ui preview`，打开 `http://127.0.0.1:5173/preview.html?page=threads&allTime=1`。开发入口向正式 App 注入模拟 UsageClient，不连接 HTTP 宿主、来源日志或原生账户。生产入口不导入预览模块。

预览通过正式组件展示任务、配置与规则样例。账户场景覆盖额度偏低／耗尽、未登录、API Key、不支持、陈旧／过期、部分、多窗口、积分、加载及刷新失败。注入宿主传输后，可在共用界面选择／确认／撤销目录；目录选择令牌会过期且只能消费一次。旧交接组件与传输模拟仍用于定向测试，覆盖已接收、部分、未知、失败、额度耗尽或不可用结果，但 App 的主要界面不提供派发入口。发送绑定复核的选择与范围。模拟宿主不调用原生接口、不修改文件，也不模拟执行或解决。切换场景重置选择、授权和规则决定。任务场景提供有界分页、搜索、排序、范围筛选、ID定位、无计量头信息、部分覆盖、切换取消及刷新失败保留旧组。配置样例展示解析诊断、历史正文不可用、分来源成员关系、原生Hook注册、调用次数及证据分页。共用价格表呈现标准／长上下文档、精确小数、缺失／零费率及更新失败。首次读取场景呈现原生头信息或SYNC_PENDING，仅停止本页等待，并可重试，不编造项目扫描百分比。这些状态复用正式组件与类型传输；旧执行／恢复模拟及私有验收档案不作为运行时输入。

来源场景区分未发现、不可读、不支持、陈旧／失败同步、会话重连和固定视图替换；已计量用量另含部分／未知金额与项目／轮次归属未知。静态规则场景通过正式建议详情展示格式诊断、资源引用和原生Hook目标，完整未发现问题的检查保留测量依据。五种原生轮次状态均可选择；中断观察按当前契约呈现为状态未知及受截断时间。

通过 `corepack pnpm --filter @wombat/ui exec node --import tsx --test tests/preview.test.ts tests/preview-hosts.test.ts tests/preview-content.test.ts tests/preview-states.test.ts` 检查模拟数据行为及宿主契约。评估与复查模拟数据使用同一公开校验器和正式组件，定向测试覆盖中英两种语言，不运行浏览器。中间阶段使用模块测试和 DOM/交互检查，完整产品集成仍在最终阶段进行。组件与样式只维护一份；新增场景通过模拟数据接入，不另写 HTML 界面。

Token 计算预览：打开 `preview.html?scenario=token-calculated&page=usage&allTime=1&lang=zh`；将 `scenario` 改为 `token-partial-calculated` 可查看有记录缺口的计算小计。两个场景使用正式总览、任务和轮次组件及合成响应，展示计算依据、原始字段缺口和独立的价格覆盖；刷新保留 URL 选择。

执行过程预览：在同一开发服务打开 `preview.html?previewModule=execution&lang=zh`。预览注入模拟的 typed UsageClient，使用正式轮次组 hook 和组件；模拟事实通过生成的耗时校验器，不维护另一套展示输入模型。提供完整、时间缺失、进行中、大量操作、空结果、加载和失败场景。

执行过程绑定正在展示的轮次结果 snapshotRef。首次耗时加载时保留用量；刷新保留旧用量/耗时/证据组，两个替换查询确认同版后一起切换，失败保留旧组。目标或范围变化取消本次连接并丢弃迟到结果；版本过期停止新证据读取，提供显式整组刷新。区间导航消费内核不透明页定位；定位不可用时不把第一页当作相关记录。分享另行请求同一固定版本的 share-v1，预览和复制原样返回对象，不加入本机标题或路径。浏览器只展示内核相对轨道、测量、零值、未知和暂定状态，不配对事件或计算汇总。命令、压缩、推理和 MCP 轨道使用同一视图；类别并集、累加与交集耗时均由内核提供。Skill/MCP 使用消费内核完整轮次总计及独立对象／记录页，区分全轮与已关联次数、重放、候选、失败结果和归属未知。分页、取消及过期固定同一快照；过期要求整组刷新。分享只导出数值使用总计，不含对象路径或服务器身份。

独立 mock 与服务端 DOM 渲染检查覆盖固定身份、替换/失败/过期、取消、五种状态、列表降级、并发口径及双语。真实内核的 CLI/HTTP 链路、正式页面与共享预览的浏览器交互通过 `verify:e2e` 验证，入口和要求见[开发流程](workflow.md)。合成来源上的 DOM、交互与溢出检查不等于像素级视觉、所有辅助技术或真实来源验收；具体运行证据保留在任务和验证工具报告中。

更多测量也展示耗时 DTO 中的工作事实：操作结果、文件变更记录和报告路径、物理用户输入/注入上下文/推理记录。按命令标签归类的时长当前不支持；新增和删除行数因没有历史仓库基线而未知。未知与零分开显示，来源状态和部分覆盖保持可见。报告路径包含失败或拒绝等终态，但不能证明文件实际写入或净变化；用户计数是物理记录数，不是请求数。失败表示来源操作结果，不代表代码缺陷。

重复调用与读取面板使用核心汇总。展开请求出现记录或计算覆盖范围，可查看统计依据、耗时覆盖与限制。有缺口时在次数旁说明观察范围。生产执行预览提供固定模拟的正向次数、时间缺口与 MCP 匹配缺口；两种语言使用同一组件。计算与分享口径见[核心参考](../reference/core.md)。

旧独立原型由 `corepack pnpm preview:retire -- --source <目录> --evidence <外部档案目录>` 先检查，再添加 `--apply` 清理。工具仅允许指定升级目录，拒绝已跟踪文件和符号链接，核对清单后移除重复实现；只保存 JSON 历史检查档案。中断后重新运行同一命令恢复。历史档案不作为当前浏览器验收证据。

概览提供上一周期贡献对比，任务详情提供会话及子会话对比，两者固定当前数据版本并连接现有证据入口。概览和任务列表显示最近成功发布的刷新变化；计算和限制见 [核心参考](../reference/core.md)。

用量页和任务详情按需展开任务分布；用量页还提供预算设置、提醒查看及仅在面板挂载期间运行的自选检查循环。配置清单显示所选范围内无使用记录的时间段；后续详情显示版本匹配的读取、加载和前后任务总体。展示只消费注入客户端，[核心语义](../reference/core.md)保持权威。
