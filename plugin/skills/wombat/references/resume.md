# Resume work

Keep the selected project and work item. Recover prior decisions, current delivery, open questions and the next action. A chat can contain several work items. A work item can span chats. Do not equate a chat title with verified work identity.

If history is needed, use [conversation](conversation.md) to locate relevant messages, then read only the decision and delivery context. Search exact task names, artifact paths or known terms before broad exploration. Prefer explicit task and artifact links. Label inferred links as candidates.

Inspect the current artifact version only when it affects the next decision. Separate a recorded claim of completion from an independently checked result. Missing completion evidence does not prove unfinished work.

Answer with the recovered decision, current known state and a concrete next action. Attach the few source locations needed to continue. Do not run usage analysis, configuration inventory or all checks merely to resume work.
