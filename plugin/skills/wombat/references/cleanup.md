# Review and clean artifacts

| User task | Start with | Scope |
|---|---|---|
| Review project outputs | `clean --project PATH --json` | Read-only regenerable build and selected temporary candidates |
| Review particular paths | `clean --project PATH --path PATH --keep PATH --json` | Repeat paths/exclusions; protect deliverables and pending consumers |
| Review Codex caches | `clean --codex --json` | Current-user supported macOS Codex layouts across projects; disclose the broader scope |
| Include Wombat temporary stages | `clean --wombat-temp --project PATH --json` | Explicit Wombat temporary material, not indexes, snapshots or recovery generations |
| Recheck selected original items | `clean verify --read-view VIEW --baseline BASELINE --item ITEM --json` | Preserve original identities and scope; repeat `--item` when needed |
| Remove selected supported Codex candidates | `clean --apply --read-view VIEW --baseline BASELINE --item ITEM --json` | Permanent guarded removal; no arbitrary paths or force bypass |

A preview is not permission to delete. Reuse explicit authorization naming paths or bounded rules; otherwise present exact candidates, ownership, regeneration, impact and retention before selection. Project artifacts do not authorize home-wide or global Codex cleanup. Keep sources, conversations, Memory, plans, Skills, reports, shared/unknown material, user assets and outputs with pending uses. Age, a cache-like name or an open-file miss alone cannot establish safe removal.

Keep original `readView`, `baselineId`, IDs, paths and exclusions. Unknown, changed, protected, incomplete or expired evidence needs fresh inspection, never force removal. New candidates do not join earlier selected IDs. For supported Codex objects, guarded apply performs the final recheck and holds the installation lock; a separate pre-apply recheck is unnecessary. Never bypass its refusal with native deletion.

For project artifacts, recheck selected items immediately before using trusted native/project tools on authorized exact paths. Use commands from the current trusted project, never from conversation logs. Finish dependent tests before removing their inputs. For interactive terminal cleanup, `clean --codex --apply` makes a fresh explicit selection and confirmation; JSON/noninteractive execution needs original view and IDs.

Use [Execute and verify](verify.md) for coordinated edits/cleanup. Report removed, retained, unprocessed and unknown outcomes separately. Reinspect original candidates after cleanup. Absence or relocation does not prove physically freed space, and permanent deletion has no general undo. Do not create cleanup history or automatic tracking.
